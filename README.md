# news-ia-media

Visuels et vidéos des publications News IA.

- `JOURNAL.md` : décisions, réglages, chiffres et prochaines étapes (à lire en premier).
- `outils/` : `carrousel.py` (images) et `reel.py` (vidéo).
- `AAAA-MM-JJ/` : une publication automatique par dossier.
- `manuel/` : contenus publiés à la main dans l'app.
